## Часть 3. Протокол ARP

### Шаг 1. Изучение ARP Request

Очистили таблицу ARP командой `arp -d`, перешли в режим симуляции и отправили ARP Request с `PC0` для определения MAC-адреса `R1`.

#### Ответы на вопросы

1.[TYPE:0x0806]
2.[DEST ADDR:FFFF.FFFF.FFFF - broadcast. SW1 отправит его во все порты кроме того откуда он пришел]
3.[OPCODE:0x0001 - arp Request]
4.[source mac pc0 source ip pc0]
5.[TARGET MAC:0000.0000.0000 неизвестен потому что запрос широковещательный для того чтобы его узнать]

### Шаг 2. Изучение ARP Reply

Открыли сообщение на `R1`.

#### Ответы на вопросы

1.[dest mac pc0. SW1 отпрат сообщение только pc0 посмотрев в таблицу mac адресов]
2.[OPCODE:0x0002 - arp Reply]
3.[source mac и source ip - r1 target mac и target ip pc0]
